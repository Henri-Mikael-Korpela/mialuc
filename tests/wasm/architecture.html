How mialuc, the compiler of Mialu, which is written in C, turns a source file into a program. The stages run one after the other, in the order of the arrows, and each is one file of src. Choose a stage to read what it takes, what it gives and where its code is.

  • Front end: reads the source
  • Middle: understands the program
  • Back end: makes the output
  • Support: used by the stages

The commands

ModeStages that run
build, runEverything, to the target that is chosen: x64-win32, wasm or wat. run then starts the program.
dump-asmEverything, to the x64 text.
dump-astThe tokenizer and the parser: the tokens and the syntax tree as written.
dump-typesUp to the specializer: the type of each name, with the copies that it makes.
dump-outline, dump-struct-sizesUp to the semantic analysis: what an editor shows for a file.
